⚠️ 安装时弹出「Windows 已保护你的电脑」怎么办

这是 Windows 对未签名安装包的常规提示（个人开发者签名证书约 ¥1000/年，暂无），不是病毒。按下面操作即可：

  1. 弹窗上点击 「更多信息」（小字，别点“确定/取消”）
  2. 出现 「仍要运行」 按钮，点它
  3. 之后按正常安装向导下一步即可

?常见问题

需要联网吗？我的 Key 会被上传吗？

模型调用需要联网，API Key 只保存在你本机，不会上传到任何服务器。使用本地 Ollama 模型时可完全离线。

以后出新版本怎么更新？

当前版本需回到本页重新下载安装。后续会接入自动更新，打开应用即可检测新版。

下载到一半失败 / 速度太慢

切换上方「国内加速」线路重试；或用浏览器自带的下载管理器断点续传。

Mac 能用吗？

暂未提供 macOS 构建，Windows 版可直接使用。
